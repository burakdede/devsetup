# Tools installed from upstream GitHub releases, because APT has no package
# or ships one too old to be useful.
#
# Format: command|repo|asset_regex|mode|binary
#
# The asset_regex may use two architecture placeholders, substituted with this
# machine's architecture at install time. Never hardcode an architecture here:
# doing so silently breaks the arm64 install (an Ubuntu VM on an Apple Silicon
# Mac is the common case).
#
#   {deb_arch}   Debian naming    amd64 / arm64
#   {gnu_arch}   GNU triple       x86_64 / aarch64
#   {node_arch}  Node/JS naming   x64 / arm64
#
# Install modes: raw (a bare binary), tar.gz / tar.xz (tarballs),
#                gz (a single gzipped binary).
